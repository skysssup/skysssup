# sky

I build small tools I actually run on my machine. GitHub: github.com/skysssup · site: https://skysssup.github.io/

- [airforge](https://github.com/skysssup/airforge) — draw shapes, turn them into Rapier bodies (webcam optional) · [demo](https://skysssup.github.io/airforge/)
- [ghost-notetaker](https://github.com/skysssup/ghost-notetaker) — sticky notes that stay off screen share
- [recall-ai](https://github.com/skysssup/recall-ai) — spaced repetition for algorithm problems, SQLite
- [agentcrucible](https://github.com/skysssup/agentcrucible) — fault-inject mock tools, grade damage vs lying (scripted agents)
- [localpulse](https://github.com/skysssup/localpulse) — LLM cost/latency metrics on disk · [demo](https://skysssup.github.io/localpulse/)
- [spanforge](https://github.com/skysssup/spanforge) — inspect agent/LLM call spans locally · [demo](https://skysssup.github.io/spanforge/)
- [shipgate](https://github.com/skysssup/shipgate) — optional post-agent secret scan + commit + push, with undo · [demo](https://skysssup.github.io/shipgate/)
- [moltdao](https://github.com/skysssup/moltdao) — toy USDC governance: agents vote, humans fund
