# Hi, I'm Sky

I build developer tools and interactive software, mostly in TypeScript and Python. My projects explore how software behaves: how a sketch becomes a physics scene, how an agent handles a failed tool call, and how a Git workflow can catch mistakes before a commit.

I'm interested in reinforcement learning and robotics. My current work spans browser graphics, local applications, and tools for testing software behavior.

### What I'm building

- **[AirForge](https://github.com/skysssup/airforge)** — a sketch-to-physics playground built with Three.js and Rapier, with optional webcam gestures and scene replay.
- **[AgentCrucible](https://github.com/skysssup/agentcrucible)** — a fault-injection harness for scripted agents, with mock tools and evidence-linked grading of unsafe actions and false success claims.
- **[Shipgate](https://github.com/skysssup/shipgate)** — a Git CLI that scans staged changes for credential patterns and applies local commit and push policies.
- **[Recall](https://github.com/skysssup/recall-ai)** — a local spaced-repetition app for algorithm practice, with SQLite scheduling and optional LeetCode result capture.

I work with TypeScript, Python, React, Node.js, SQLite, Three.js, and Rapier.
